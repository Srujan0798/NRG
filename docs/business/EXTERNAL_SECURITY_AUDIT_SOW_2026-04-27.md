# External Security And DPDP Audit SOW

**Objective:** Obtain a third-party assurance letter for NRG before ministry or enterprise deployment.

## Scope

- API penetration test against the sovereign URL.
- DPDP 2023 controls review for data minimization, purpose limitation, consent, deletion, and auditability.
- Kubernetes and Helm configuration review.
- PostgreSQL, PgBouncer, Qdrant, Redis, and Kong hardening review.
- Red-team replay validation using `scripts/red_team_live_replay.py`.
- Audit-chain non-repudiation review and recovery drill observation.

## Deliverables

- Signed statement of work.
- Findings register with severity, owner, remediation, and retest status.
- Final assurance letter.
- Executive summary suitable for IIT-GN, buyer, and investor diligence.

## Acceptance

No unresolved Critical or High findings. Medium findings either remediated or accepted with signed mitigation plan.
