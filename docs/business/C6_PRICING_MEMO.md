# C6 Pricing Memo

**Status:** Founder draft  
**Date:** 2026-04-28

## Packages

| Package | Buyer | Price | Scope |
|---|---|---:|---|
| Researcher | Individual researchers and labs | Free / freemium | limited search, citation views, public datasets, no private deployment |
| Government | Ministry, state mission, public university | INR 18L setup + INR 14L/year | sovereign deployment, aggregate access, 50M rows, UAT, quarterly DR drill |
| Enterprise | R&D enterprise, private university group, PSU | Custom, starting INR 40L setup + INR 30L/year | 600GB ingest, dedicated environment, external audit support, SLA, custom integrations |

## Commercial Assumptions

- Buyer provides data rights and source-system access.
- External audit, travel, and hardware/cloud costs are pass-through unless explicitly bundled.
- Any PII-bearing data requires a signed data-processing agreement.
- Government package prioritizes aggregate and policy views; Enterprise package includes custom connectors and support SLAs.
