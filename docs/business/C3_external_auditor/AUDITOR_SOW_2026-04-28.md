# C3 External Auditor SOW

**Status:** Draft request for CERT-In empaneled or equivalent external auditor  
**Owner:** Founder + Security auditor

## Scope

- DPDP 2023 compliance review.
- ISO 27001 control mapping review for the sovereign deployment.
- API penetration test against the sovereign URL.
- Kubernetes, Helm, Kong, PostgreSQL, PgBouncer, Qdrant, Redis, and backup configuration review.
- Red-team replay observation using `scripts/red_team_live_replay.py`.
- Audit-chain non-repudiation and disaster-recovery drill review.

## Deliverables

- Signed statement of work.
- Auditor acknowledgement email.
- Findings register with severity, owner, remediation, and retest status.
- Final assurance letter.

## Acceptance Criteria

- No unresolved Critical or High findings.
- Medium findings either remediated or accepted with signed mitigation.
- Final letter references DPDP 2023, penetration test, and sovereign deployment scope.
