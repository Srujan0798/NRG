# EXPERIMENTAL - Knowledge Graph Module

**Status: Phase 2 Pending**

This module is experimental and not yet integrated into the production pipeline.

## Components

- `loader.py`: Neo4j data loader (requires Neo4j running)
- `traversals.py`: Graph traversal queries

Future work will connect this to the LangGraph orchestration for:
- Graph-based research discovery
- Collaboration network analysis
- Citation graph traversal

Not wired to:
- Orchestration pipeline
- API endpoints
- Query router

Use only for development/testing with Neo4j.
