RECOMMENDATIONS (cluster-gated)
===============================
1. Pre-warm cache with Dhairya 17 queries at API startup
2. Add Redis layer for cross-process cache sharing
3. Add LLM timeout (5s max synthesis) — already active, not enough under load
4. Rule-based SQL fast-path — already active, bypasses LLM for known shapes
5. Pre-connect DB pool at startup (not lazy)
6. Move refresh-token persistence off SQLite for load runs
7. Separate login ramp-up from steady-state /query latency measurement
