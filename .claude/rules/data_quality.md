# Data Quality Drift Protocol

WE.6 owns the seven-pillar scorecard for production data quality. The scorecard is generated by `scripts/data_quality_scorecard.py` and must run against local SQLite before any live database target is used.

## Command

```bash
python3 scripts/data_quality_scorecard.py \
  --database-url sqlite:///nrg_research.db \
  --json-output docs/ops/data_quality_scorecard.json \
  --markdown-output docs/ops/data_quality_scorecard.md
```

Use `--fail-on-p0` in pre-commit and CI. Use `--fail-on-fail` only for environments with a fully seeded representative database.

## Seven Pillars

| Pillar | Threshold | Severity |
| --- | --- | --- |
| Schema coverage | 58 authoritative `db_struct.sql` tables present | P1 on any missing table |
| Referential integrity | >=99% valid references | P0 when <90%, P1 from 90-98.99% |
| Null rate | <=5% nulls in any measured column | P1 |
| Freshness | Latest table update within 7 days | P1 |
| Completeness | >=1000 rows in each core table | P1 |
| Consistency | Zero cross-table orphan violations | P1 |
| PII sanitization | Zero PII findings in non-PII tables | P0 |

## P0 Conditions

- Any Aadhaar, PAN, phone, email, or GSTIN pattern found in a non-PII table.
- Referential integrity score below 90%.
- Scorecard execution error in production.

## Outputs

- JSON: `docs/ops/data_quality_scorecard.json`
- Markdown: `docs/ops/data_quality_scorecard.md`
- Prometheus: `nrg_data_quality_pillar_status`, `nrg_data_quality_pillar_score`, `nrg_data_quality_p0_alerts`
- Grafana: `infrastructure/monitoring/dashboards/09_data_quality.json`

## Governance

- Pre-commit blocks P0 data quality regressions.
- Weekly automation commits the JSON and Markdown scorecard to `docs/ops/`.
- `/self-evolve` must compare the current schema coverage and consistency pillars with the last committed scorecard before proposing schema changes.
- New tables must declare whether they are PII-bearing. Unknown tables default to non-PII unless their name clearly indicates user, researcher, faculty, profile, consent, or registration data.
