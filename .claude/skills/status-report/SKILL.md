# /status-report

Generate a structured status report with KPIs, risks, and action items.

## Usage

```
/status-report $ARGUMENTS
```

## Workflow

### 1. Gather Data

- Project / initiative name and reporting period
- Key milestones and their status
- KPIs and metrics
- Recent accomplishments
- Blockers and risks
- Upcoming priorities

### 2. Assess Health

Color-code each area:
- **Green**: On track, no issues
- **Yellow**: At risk, needs attention
- **Red**: Off track, intervention required

Areas to score: scope, schedule, budget, quality, team health, stakeholder satisfaction

### 3. Structure the Report

- **Executive summary**: 2-3 sentences on overall health
- **Accomplishments**: What got done
- **Metrics**: KPIs with trends
- **Risks and blockers**: What's in the way
- **Decisions needed**: What stakeholders must decide
- **Next period priorities**: What is coming

### 4. Follow Up

- Distribute to stakeholders
- Track action items to closure
- Update risk register

## Output

Formatted status report with health indicators, metrics, risks, and clear action items.
