# /process-optimization

Analyze and improve business processes to remove waste and increase throughput.

## Usage

```
/process-optimization $ARGUMENTS
```

## Workflow

### 1. Map the Current State

- Document the as-is process
- Identify every step, handoff, and decision
- Measure cycle time and wait time at each stage

### 2. Identify Waste

Common sources of waste:
- Excess handoffs
- Waiting / idle time
- Redundant approvals
- Rework loops
- Over-processing
- Unnecessary motion or context switching

### 3. Root Cause Analysis

- Why does each bottleneck exist?
- Is it structural, cultural, or tooling-related?
- What constraints are real vs assumed?

### 4. Design Future State

- Eliminate, combine, or parallelize steps
- Automate where appropriate
- Redesign handoffs and ownership

### 5. Implementation Plan

- Prioritized improvements
- Quick wins vs structural changes
- Success metrics

## Output

Current state map, waste analysis, future state design, and prioritized improvement roadmap.
