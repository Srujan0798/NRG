# /brainstorm

Brainstorm a product idea, problem space, or strategic question.

## Usage

```
/brainstorm <topic or question>
```

## When to Use

- Early-stage idea exploration
- Breaking out of conventional thinking
- Finding creative solutions to hard problems
- Stress-testing a direction before committing

## Workflow

1. **Clarify the question** — What's the real problem we're solving?
2. **Explore widely** — Generate diverse ideas without filtering
3. **Build on ideas** — "Yes, and..." to expand promising directions
4. **Stress-test** — What would make this fail? What are we missing?
5. **Converge** — Pick 2-3 directions worth pursuing

## Rules

- No idea is stupid in phase 1
- Quantity before quality
- Challenge assumptions aggressively
- End with actionable next steps
