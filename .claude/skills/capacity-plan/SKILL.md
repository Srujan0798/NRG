# /capacity-plan

Plan resource capacity by analyzing workload, utilization, and forecasting needs.

## Usage

```
/capacity-plan $ARGUMENTS
```

## Workflow

### 1. Gather Inputs

- Team composition and roles
- Current workload and allocations
- Upcoming projects and initiatives
- Historical utilization data
- Any known constraints (budget, headcount limits, skills gaps)

### 2. Analyze Current State

- Calculate current utilization by person / team / role
- Identify overallocation and underutilization
- Map skills to demand

### 3. Forecast Future State

- Model upcoming project demand against available capacity
- Identify gaps and surpluses
- Scenario-plan: hire vs deprioritize vs extend timeline

### 4. Recommendations

- Capacity plan with options
- Risk areas where demand exceeds supply
- Mitigation strategies

## Output

Structured capacity analysis with utilization tables, forecast charts, and actionable recommendations.
