# /product-brainstorming

Brainstorm product ideas, explore problem spaces, and challenge assumptions.

## Usage

```
/product-brainstorming <topic or problem>
```

## When to Use

- Exploring a new opportunity
- Generating solutions to a product problem
- Stress-testing an idea
- Thinking out loud before converging on a direction

## Workflow

1. **Frame the problem** — Define the user pain point or opportunity clearly
2. **Diverge** — Generate many ideas without judgment
3. **Challenge assumptions** — Question constraints and sacred cows
4. **Converge** — Group ideas into themes, rank by impact/effort
5. **Next steps** — Pick top ideas for validation

## Techniques

- **How Might We** — Reframe problems as opportunity statements
- **Crazy 8s** — Sketch 8 solutions in 8 minutes
- **Assumption Mapping** — List assumptions, test riskiest first
- **Impact/Effort Matrix** — Plot ideas for prioritization
