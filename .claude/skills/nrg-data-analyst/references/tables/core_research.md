# Core Research Tables

This document contains the core NRG schema tables: researchers, institutions, publications, labs, funding, and keywords.

---

## Quick Reference

### Business Context
The core schema represents India's research ecosystem: researchers affiliated with institutions, producing publications, working in labs, and receiving funding. This is the primary data domain for researcher discovery and research output analytics.

### Entity Clarification
**"Institute" can mean:**
- **Institution** (core): UUID-linked entity in `institutions` table
- **Institute** (academic): TEXT name in academic schema tables
- **Always clarify** which schema you're querying

### Standard Filters
```sql
-- Respect access tier (RLS-enforced, but explicit for clarity)
WHERE access_tier <= :user_tier

-- Exclude test data
AND name NOT ILIKE '%test%'
AND name NOT ILIKE '%sample%'
```

## Key Tables

### researchers
**Location**: `public.researchers`
**Description**: Individual researchers, scientists, and academics. Primary entity for researcher discovery.
**Primary Key**: `researcher_id` (UUID)
**Update Frequency**: Weekly batch (1-7 day lag)

| Column | Type | Description | Notes |
|--------|------|-------------|-------|
| **researcher_id** | UUID | Unique identifier | Generated by `gen_random_uuid()` |
| **name** | VARCHAR(255) | Full name | NOT NULL |
| **email** | VARCHAR(255) | Institutional email | UNIQUE; NULL for unverified profiles |
| **phone** | VARCHAR(20) | Contact number | PII — government tier only |
| **orcid** | VARCHAR(20) | ORCID iD | NULL if not available; key for dedup |
| **state** | VARCHAR(100) | Indian state | Free-text; may need normalization |
| **research_area** | VARCHAR(255) | Primary research domain | Free-text; e.g., 'Machine Learning', 'Biotech' |
| **year_joined** | INTEGER | Year researcher started career | NULL if unknown |
| **access_tier** | INTEGER | Visibility: 1=public, 2=industry, 3=academic, 4=govt | CHECK (1,2,3) in seed; tier 4 added for government |
| **created_at** | TIMESTAMP | Record creation | UTC |
| **updated_at** | TIMESTAMP | Last update | UTC |

**Indexes**: `idx_researchers_state`, `idx_researchers_research_area`, `idx_researchers_tier`

**Relationships**:
- → `funding` (1:many via `researcher_id`)
- → `institutions` (implicit via `state` — APPROXIMATE linkage)
- → `publications` (NO direct FK; link via ORCID or name text search)

**Sample Queries**:
```sql
-- Top researchers by h-index in AI
SELECT name, h_index, state, research_area
FROM researchers
WHERE research_area ILIKE '%artificial intelligence%'
  OR research_area ILIKE '%machine learning%'
ORDER BY h_index DESC NULLS LAST
LIMIT 20;

-- Researcher count by state
SELECT state, COUNT(*) AS researcher_count
FROM researchers
WHERE state IS NOT NULL
GROUP BY state
ORDER BY researcher_count DESC;
```

### institutions
**Location**: `public.institutions`
**Description**: Universities, IITs, NITs, research centers, and academic organizations.
**Primary Key**: `institution_id` (UUID)
**Update Frequency**: Monthly batch

| Column | Type | Description | Notes |
|--------|------|-------------|-------|
| **institution_id** | UUID | Unique identifier | |
| **name** | VARCHAR(255) | Institution name | NOT NULL; should be unique |
| **type** | VARCHAR(50) | Category: 'IIT', 'NIT', 'University', etc. | Free-text; standardize in queries |
| **state** | VARCHAR(100) | Indian state | |
| **country** | VARCHAR(100) | Country | DEFAULT 'India' |
| **founded_year** | INTEGER | Year established | NULL if unknown |
| **website** | VARCHAR(255) | Official URL | |
| **access_tier** | INTEGER | Visibility tier | DEFAULT 1 |
| **created_at** | TIMESTAMP | Record creation | |
| **updated_at** | TIMESTAMP | Last update | |

**Indexes**: `idx_institutions_type`, `idx_institutions_state`

**Relationships**:
- → `labs` (1:many via `institution_id`)
- → `funding` (1:many via `institution_id`)
- → `researchers` (implicit via `state`)

**Sample Queries**:
```sql
-- Institutions by type
SELECT type, COUNT(*) AS count
FROM institutions
GROUP BY type
ORDER BY count DESC;

-- Oldest institutions
SELECT name, type, state, founded_year
FROM institutions
WHERE founded_year IS NOT NULL
ORDER BY founded_year
LIMIT 20;
```

### publications
**Location**: `public.publications`
**Description**: Research papers, articles, and scholarly works.
**Primary Key**: `publication_id` (UUID)
**Update Frequency**: Weekly batch (1-7 day lag)

| Column | Type | Description | Notes |
|--------|------|-------------|-------|
| **publication_id** | UUID | Unique identifier | |
| **title** | VARCHAR(1000) | Paper title | NOT NULL; searchable |
| **abstract** | TEXT | Paper abstract | NULL if unavailable |
| **venue** | VARCHAR(255) | Journal or conference | NULL for preprints |
| **year** | INTEGER | Publication year | Indexed |
| **doi** | VARCHAR(50) | Digital Object Identifier | NULL for unpublished; unique |
| **pmid** | VARCHAR(20) | PubMed ID | NULL if not biomedical |
| **access_tier** | INTEGER | Visibility tier | DEFAULT 1 |
| **created_at** | TIMESTAMP | Record creation | |
| **updated_at** | TIMESTAMP | Last update | |

**Indexes**: `idx_publications_year`, `idx_publications_venue`

**Relationships**:
- → `researchers` (NO direct FK; link via ORCID or text search on title/abstract)
- → `keywords` (NO direct FK; keyword extraction from text)

**Sample Queries**:
```sql
-- Publications by year
SELECT year, COUNT(*) AS pub_count
FROM publications
WHERE year >= 2015
GROUP BY year
ORDER BY year;

-- Search by keyword in title
SELECT title, year, venue, doi
FROM publications
WHERE title ILIKE '%renewable energy%'
ORDER BY year DESC;
```

### labs
**Location**: `public.labs`
**Description**: Research laboratories and groups within institutions.
**Primary Key**: `lab_id` (UUID)
**Update Frequency**: Monthly batch

| Column | Type | Description | Notes |
|--------|------|-------------|-------|
| **lab_id** | UUID | Unique identifier | |
| **name** | VARCHAR(255) | Lab name | NOT NULL |
| **institution_id** | UUID | Parent institution | FK → institutions |
| **research_area** | VARCHAR(255) | Lab's focus area | |
| **established_year** | INTEGER | Year founded | |
| **website** | VARCHAR(255) | Lab URL | |
| **access_tier** | INTEGER | Visibility tier | DEFAULT 1 |
| **created_at** | TIMESTAMP | Record creation | |
| **updated_at** | TIMESTAMP | Last update | |

**Indexes**: `idx_labs_institution`, `idx_labs_research_area`

**Relationships**:
- → `institutions` (many:1 via `institution_id`)

**Sample Queries**:
```sql
-- Labs per institution
SELECT i.name AS institution, COUNT(l.lab_id) AS lab_count
FROM institutions i
LEFT JOIN labs l ON i.institution_id = l.institution_id
GROUP BY i.institution_id, i.name
ORDER BY lab_count DESC;
```

### funding
**Location**: `public.funding`
**Description**: Research grants, awards, and financial support.
**Primary Key**: `funding_id` (UUID)
**Update Frequency**: Monthly batch (7-30 day lag)

| Column | Type | Description | Notes |
|--------|------|-------------|-------|
| **funding_id** | UUID | Unique identifier | |
| **researcher_id** | UUID | Grant recipient | FK → researchers |
| **institution_id** | UUID | Host institution | FK → institutions |
| **agency** | VARCHAR(255) | Funding body | Free-text; e.g., 'DST', 'DBT', 'ISRO' |
| **amount** | DECIMAL(15,2) | Grant amount (INR) | NULL if undisclosed |
| **start_date** | DATE | Grant start | |
| **end_date** | DATE | Grant end | NULL if ongoing |
| **title** | VARCHAR(500) | Grant title | |
| **access_tier** | INTEGER | Visibility tier | DEFAULT 1 |
| **created_at** | TIMESTAMP | Record creation | |
| **updated_at** | TIMESTAMP | Last update | |

**Indexes**: `idx_funding_researcher`, `idx_funding_institution`, `idx_funding_agency`

**Relationships**:
- → `researchers` (many:1 via `researcher_id`)
- → `institutions` (many:1 via `institution_id`)

**Sample Queries**:
```sql
-- Top funding agencies
SELECT agency, COUNT(*) AS grant_count, SUM(amount) AS total_amount
FROM funding
WHERE amount IS NOT NULL
GROUP BY agency
ORDER BY total_amount DESC
LIMIT 10;

-- Funding timeline
SELECT DATE_PART('year', start_date) AS year,
       SUM(amount) AS total_funding,
       COUNT(*) AS num_grants
FROM funding
WHERE start_date IS NOT NULL
GROUP BY DATE_PART('year', start_date)
ORDER BY year;
```

## Common Gotchas

1. **No researcher-publication junction table**: Publications exist standalone. To find a researcher's papers, use `ORCID` matching or text search on `title`/`abstract`.

2. **Academic schema uses TEXT institute names**: Tables like `innovation_grant_from_govt` use `institute TEXT` instead of `institution_id UUID`. Join by name matching, not FK.

3. **Funding amounts may be NULL**: Some grants don't disclose amount. Always use `WHERE amount IS NOT NULL` for financial aggregations.

4. **State field is free-text**: Both `researchers.state` and `institutions.state` are VARCHAR. Same state may have variant spellings.

5. **Access tier in seed is CHECK(1,2,3) but system supports 4**: The seed schema limits to 1-3, but government tier = 4 exists at runtime. RLS handles this.
