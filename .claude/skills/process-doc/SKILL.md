# /process-doc

Document a business process with flowcharts, RACI matrices, and standard operating procedures.

## Usage

```
/process-doc $ARGUMENTS
```

## Workflow

### 1. Understand the Process

- Purpose and scope
- Trigger and endpoint
- Key steps and decision points
- Exceptions and edge cases

### 2. Identify Actors

- Who performs each step
- Who is consulted or informed
- Escalation paths

### 3. Create Artifacts

- **Flowchart**: Visual representation of the process
- **RACI**: Responsible, Accountable, Consulted, Informed matrix
- **SOP**: Step-by-step written procedure with inputs, outputs, and quality checks

### 4. Validate

- Review with process owners
- Check for missing steps or handoffs
- Confirm exception handling

## Output

Process documentation package: flowchart, RACI matrix, and SOP document.
